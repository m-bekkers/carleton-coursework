Exercise 4:

Write a short step-by-step explanation of how Python evaluates the
statement:

x *= x + x

when x refers to 5.

Python first evaluates what is on the right of the operator. This ends up being 
10, as 5 + 5 = 10. Then, Python evaluates the *= operator, which can be 
rewritten as x = x * 10. This evaluates to x = 50.
